# AI-SOC Assistant

AI-SOC Assistant is a personal **Cybersecurity & SOC Automation** project that uses Wazuh and AI to assist SOC analysts in analyzing security alerts.

## Architecture

Wazuh Alert → Parser → Alert Formatter → Threat Intelligence → Risk Engine → Incident Classification → Evidence Assessment → AI SOC Analysis → Incident Report

## Key Features

- Wazuh security alert processing
- Threat intelligence context
- Risk assessment
- Incident classification
- Evidence-based SOC reasoning
- AI-powered security analysis
- Structured incident reporting

## Evidence-Based Analysis

The system distinguishes between:

- **Confirmed Facts**
- **Interpretations**
- **Unconfirmed Possibilities**

This helps reduce unsupported security conclusions and AI hallucinations.

## Technologies

Python • Wazuh • Google Gemini API • Threat Intelligence APIs • REST APIs • JSON • Git
